# SmartPlant S3 — куди що підключається

## Сенсори (живлення 3.3V від ESP32)

- GPIO1 — I2C SDA → BME280 + BH1750
- GPIO2 — I2C SCL → BME280 + BH1750
- GPIO3 — аналоговий вхід (ADC1) → ґрунтова вологість, резистивний датчик
- GPIO14 — OneWire → DS18B20, термодатчик ґрунту
  (потрібен pull-up резистор 4.7 кОм між DATA і 3.3V; фізично на іншому
  ряду пінів плати (J1), ніж решта сенсорів (J3) — зручніше для проводки)

## Камера OV3660 (живлення 3.3V)

- GPIO4 — SIOD (SCCB SDA)
- GPIO5 — SIOC (SCCB SCL)
- GPIO6 — VSYNC
- GPIO7 — HREF
- GPIO8 — Y4
- GPIO9 — Y3
- GPIO10 — Y5
- GPIO11 — Y2
- GPIO12 — Y6
- GPIO13 — PCLK
- GPIO15 — XCLK
- GPIO16 — Y9
- GPIO17 — Y8
- GPIO18 — Y7
- PWDN, RESET — не підключені

## Актуатори (окреме зовнішнє живлення, через реле/MOSFET/драйвер)

- GPIO47 — реле помпи → насос (напруга — уточнити, зазвичай 12V DC)
- GPIO40 — вентилятор циркуляції, on/off → блок "вентилятор + PTC-радіатор"
- GPIO42 — нагрівач PTC, ШІМ → той самий блок "вентилятор + PTC-радіатор", 12V
  (один фізичний вузол, два окремі дроти — GPIO40 і GPIO42)
- GPIO38 — витяжка, on/off, окремий незалежний вентилятор (напруга — уточнити)
- GPIO39 — грілка-мат ґрунту, ШІМ, 12V/24V
- GPIO45 — LED-драйвер струму, ШІМ димування → один діод ~900 мА, максимум
  обрізано прошивкою до 25% (`light_brightness` не вище 63 з 255)
  (напруга живлення драйвера — уточнити; strapping-пін, звірити підтяжку входу з драйвером)

## Живлення

- ESP32 (логіка, Wi-Fi): пін **5V** на лівому ряду пінів плати (J1), одразу
  біля GND, поруч із GPIO14 — від зовнішнього стабілізатора/перетворювача
  напруги (не через USB-C). USB-C і пін 5V — **взаємовиключні**, одночасно
  живити з обох не можна (ризик пошкодження плати). USB-C лишається лише
  для прошивки/моніторингу — тоді зовнішнє 5V на час підключення USB
  від'єднати.
- Актуатори: окремий зовнішній блок живлення, 12V або 12/24V — залежно від модуля
- GND усіх модулів (реле/MOSFET/LED-драйвер, і зовнішнього 5V-стабілізатора)
  має бути з'єднаний із GND ESP32

## Не чіпати

- GPIO22–25 — фізично не існують на ESP32-S3
- GPIO26–37 — зайняті октальною PSRAM/flash (модуль N16R8)
- GPIO19–20 — нативний USB (D-/D+)
- GPIO0, 3, 45, 46 — strapping-піни (3 і 45 тут уже свідомо використані з застереженнями вище)
