# SmartPlant S3 — апаратне забезпечення

## Контролер

- ESP32-S3-DevKitC-1 — модуль N16R8 (16 MB flash, 8 MB октальна PSRAM)

## Камера

- OV3660 — паралельний інтерфейс (14 сигнальних ліній + SCCB)

## Сенсори

- BME280 — температура, вологість, атмосферний тиск (I2C, 0x76 або 0x77)
- BH1750 — освітленість, лк (I2C, 0x23)
- DFRobot SEN0308 — ємнісний водозахищений датчик вологості ґрунту (аналоговий,
  0–2.9V, 4 дроти: червоний VCC, чорний GND, жовтий сигнал, окремий чорний — теж GND)
- DS18B20 — температура ґрунту (OneWire, потрібен pull-up резистор 4.7 кОм)

## Актуатори

- Насос — водяний, через реле (напруга — уточнити)
- Блок "вентилятор + PTC-радіатор" (новий) — комбінований вузол опалення:
  вентилятор on/off + PTC-нагрівач на ШІМ, 12V
- Вентилятор радіатора grow-світла — 4-пін PC-кулер 12V, через реле, вмикається разом зі світлом
- Грілка-мат ґрунту — DC, ШІМ, 12V/24V
- Grow-світло (нове) — один потужний світлодіод (~900 мА, повна яскравість 0–255, на радіаторі з вентилятором)

## Керуючі модулі

- Реле — помпа, вентилятор циркуляції, вентилятор радіатора LED
- MOSFET-модулі (ШІМ) — грілка ґрунту, PTC-нагрівач
- LED-драйвер струму (constant current) — grow-світло

## Живлення

- Зовнішній стабілізатор/перетворювач напруги → 5V — ESP32 (логіка, Wi-Fi),
  через пін 5V плати (не через USB-C; USB-C лишається лише для прошивки —
  не можна тримати підключеним одночасно зі зовнішнім 5V)
- Зовнішній блок живлення, 12V або 12/24V — актуатори, через реле/MOSFET/LED-драйвер
